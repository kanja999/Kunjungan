# Kunjungan (APK)

1. Buat repo baru di GitHub, upload SEMUA isi folder ini (termasuk folder .github).
2. Buka tab Actions > workflow "Build APK" (jalan otomatis setelah upload, atau klik Run workflow).
3. Tunggu sekitar 3-6 menit sampai hijau, klik run tersebut, lalu download "Kunjungan-APK" di bagian Artifacts.
4. Ekstrak zip-nya, kirim app-debug.apk ke HP, buka, izinkan "Instal dari sumber tidak dikenal", lalu Instal.
